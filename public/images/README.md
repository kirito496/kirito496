# Photos des études de cas

Déposez ici 4 images (format .jpg, idéalement ~1200×1400 px, cadrage portrait/carré),
avec EXACTEMENT ces noms de fichier :

| Fichier            | Étude de cas               | Thème conseillé |
|--------------------|----------------------------|-----------------|
| `reseau.jpg`       | Projet A — Refonte réseau  | infrastructure réseau, serveurs, câblage, globe connecté |
| `securite.jpg`     | Projet B — Cybersécurité   | cadenas, bouclier numérique, protection des données |
| `application.jpg`  | Projet C — Application      | code, écran de développement, application mobile |
| `marque.jpg`       | Projet D — Marque/Marketing | équipe, tableau de bord analytics, marketing |

Dès qu'un fichier est présent, la photo remplace automatiquement l'illustration
correspondante sur le site. Si un fichier est absent, l'illustration SVG reste affichée.

Astuce : utilisez des images libres de droits (Unsplash, Pexels, Pixabay) ou vos
propres captures de projets.
